# mammal-milkenergy
This repository contains the code for developing predictive relationships for daily milk intake rates and milk energy density associated with a PLOS one manuscript. The code to run the analysis can be found in the "scripts" folder. Data was sourced from published literature. The full datasets used to run the model are in a hidden folder but a subset of these datasets can be found in the "data-sub" folder so that code can be explored; the path to the input data just needs to be changed. Predictions for each species in the analysis using the full dataset can be found in the "predictions" folder.
